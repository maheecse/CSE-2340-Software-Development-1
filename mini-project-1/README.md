# MAHEE — Personal Portfolio Website

A personal portfolio website built with HTML5 and CSS3 to showcase my profile, technical skills, academic projects, and contact information.

## Overview

### Live Website

[Visit My Portfolio](https://cse-2340-software-development-1-oir.vercel.app/)

This is a single-page personal portfolio website for **Shahriar Ibne Alam Mahee**, a Computer Science & Engineering student at **International Islamic University Chittagong (IIUC)**.

The website includes my introduction, skills, projects, GitHub and LinkedIn profiles, and a contact form with a clean and minimal design.

## Features

- About section with profile image and introduction
- Skills section with technical skills
- Projects section with project descriptions and GitHub links
- Contact section with LinkedIn profile and contact form
- Internal navigation between sections
- Hover effects on navigation links and buttons
- Purple-themed clean and minimal UI
- Circular profile image with styled border
- HTML form validation using required fields and email validation

## How to Run Locally

1. Clone the repository.

2. Open the project folder.

3. Make sure the following files and folders are present:
   - `index.html`
   - `style.css`
   - `images/profile.jpg`

4. Open `index.html` in a modern web browser.

No additional dependencies or build tools are required.
