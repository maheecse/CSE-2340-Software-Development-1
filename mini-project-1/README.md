# MAHEE — Personal Portfolio Website

A responsive personal portfolio website built with **HTML5 and CSS3**, developed to showcase my profile, technical skills, academic projects, and contact information.

## Overview

### Page Link

https://cse-2340-software-development-1-oir.vercel.app/

This project is a single-page personal portfolio website for **Shahriar Ibne Alam Mahee**, a Computer Science & Engineering student at the **International Islamic University Chittagong (IIUC)**.

The website presents a personal introduction, technical skills, academic projects, GitHub and LinkedIn links, and a contact form in a clean and minimal interface.

## Features

- **Responsive Layout** — Uses flexible widths and Flexbox to provide a clean layout across different screen sizes.
- **About Section** — Includes a profile image, personal introduction, and current learning focus.
- **Skills Section** — Displays technical skills in a clean tag-style layout.
- **Projects Section** — Showcases academic projects with descriptions and direct GitHub links.
- **Contact Section** — Includes LinkedIn information and a structured contact form with name, email, and message fields.
- **Internal Navigation** — Navigation links provide quick access to About, Skills, Projects, and Contact sections.
- **Interactive Elements** — Navigation and buttons include hover effects.
- **Purple-Themed UI** — A clean and minimal design using a soft purple color palette.
- **Profile Image** — Circular profile image with a styled border.
- **Form Validation** — Required fields and email input validation are handled through HTML form attributes.
